
# Módulo Predictivo de Inventario con Inteligencia Artificial

## Descripción del proyecto

Este proyecto propone el desarrollo de un Módulo Predictivo de Inventario para Mercado Libre, utilizando Inteligencia Artificial para estimar la demanda de productos y recomendar la distribución anticipada del stock entre los diferentes centros de distribución.

El objetivo es mejorar la disponibilidad de productos, optimizar la gestión del inventario y contribuir a reducir los tiempos de entrega.

## Objetivo general

Desarrollar un módulo que utilice datos históricos y actuales para predecir la demanda de productos y generar recomendaciones de distribución de stock.

## Alcance del proyecto

El sistema contempla:

- Gestión de información de productos.
- Registro de inventario por centro de distribución.
- Análisis de datos históricos de ventas.
- Predicción de demanda mediante Inteligencia Artificial.
- Generación de recomendaciones de distribución de stock.

## Integración de las entregas

- **TP1:** Análisis de Mercado Libre como sistema abierto y propuesta del módulo.
- **TP2:** Análisis FODA, objetivos, metas y planificación mediante Gantt.
- **TP3:** Estructura organizativa y diccionario de datos.
- **TP4:** Modelado de procesos BPMN, trabajo colaborativo, control de versiones e indicadores de desempeño.
